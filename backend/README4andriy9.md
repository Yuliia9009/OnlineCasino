
##  API для фронта

| Эндпоинт | Что делает | Для чего |
|----------|------------|-----------------|
| **GET /health** | Проверка живости API | Быстрый health-check |
| **GET /api/spins/test** | Последние N спинов (smoke-test) | Проверка, что база работает |
| **GET /api/spins/history/:address** | История игр игрока (с пагинацией) | Экран «История игр» |
| **GET /api/spins/by-tx/:txHash** | Найти спин по транзакции | Разбор конкретного кейса/ошибки |
| **GET /api/spins/recent** | Лента последних спинов по всей игре | «Живая стена» активности |
| **POST /api/spins/confirm** | Принять txHash → распарсить SpinResult → записать | Основной рабочий эндпоинт (связь с блокчейном) |
| **GET /api/players/:address/summary** | Сводка по игроку (агрегаты) | Карточка «Мой профиль» |
| **GET /api/players/:address/spins** | История спинов игрока | Вкладка «История» |
| **POST /api/players/:address/recalc** | Пересчёт агрегатов игрока из сырых данных | Восстановление при рассинхроне |
| **GET /api/players/leaderboard/top** | Лидерборд игроков по метрике | Таблица «Топ-игроки» |
| **GET /api/stats/summary** | Общая сводка (ставки, выплаты, RTP) | Карточки дашборда |
| **GET /api/stats/rtp** | RTP за период (24h / 7d / 30d) | График динамики RTP |
| **GET /api/stats/leaderboard** | Топ игроков (дублирует /players) | Легко вставить в дашборд |
| **POST /api/deposits/confirm** | Принять txHash депозита → записать | Обновление баланса игрока |
| **POST /api/withdrawals/confirm** | Принять txHash вывода → записать | История и списание баланса |
