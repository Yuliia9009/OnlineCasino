
##  API для фронта


| Эндпоинт | Что делает | Для чего | Применение во фронте |
|----------|------------|----------|----------------------|
| **GET /health** | Проверяет, что API живо | Быстрый ping | Тех. страница «Сервер доступен» |
| **GET /api/spins/test** | Возвращает последние N спинов | Проверка, что БД подключена | Только для отладки |
| **GET /api/spins/history/:address** | История игр конкретного игрока (пагинация по cursor) | Смотреть все прошлые ставки/результаты | Экран «История игр» |
| **GET /api/spins/by-tx/:txHash** | Ищет спин по хэшу транзакции | Точный разбор конкретного кейса (ошибка/поддержка) | Админка / DevTools |
| **GET /api/spins/recent** | Лента последних спинов по всей игре | Живая стена активности | Виджет «Последние спины» |
| **POST /api/spins/confirm** | Принимает txHash → парсит событие SpinResult → пишет в БД | Основной мост: транзакция игрока → данные в системе | После каждой транзакции Spin |
| **GET /api/players/:address/summary** | Сводка по игроку (агрегаты: депозиты, ставки, выплаты, net) | Профиль игрока | Экран «Мой профиль» |
| **GET /api/players/:address/spins** | История только этого игрока (ограниченный список) | Для личного кабинета | Вкладка «История» |
| **POST /api/players/:address/recalc** | Пересчитывает агрегаты игрока из deposits/spins/withdrawals | Восстановление при сбое/рассинхроне | CRON / админка |
| **GET /api/players/leaderboard/top** | Топ игроков по выбранной метрике (payout, net, spins) | Таблица лидеров | Экран «Лидерборд» |
| **GET /api/stats/summary** | Общая статистика (totalBet, totalPayout, RTP) | Карточки «Всего ставок/выплат» | Дашборд |
| **GET /api/stats/rtp** | RTP за окно (24h / 7d / 30d) | Динамика эффективности игры | График RTP |
| **GET /api/stats/leaderboard** | Топ игроков (то же что /players/leaderboard) | Удобный эндпоинт для дашборда | Дашборд |
| **POST /api/deposits/confirm** | Принимает txHash депозита → пишет в БД | Обновляет баланс игрока после депозита | После транзакции Deposit |
| **POST /api/withdrawals/confirm** | Принимает txHash вывода → пишет в БД | Фиксирует вывод игрока | После транзакции Withdraw |
